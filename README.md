# Action Engine

A centralized, GitHub-native DevSecOps platform for managing security scanning, code quality, and the Software Development Life Cycle (SDLC) across multiple repositories.

Action Engine delivers automated pipelines, security checks, Excel reporting dashboards, and email notifications using GitHub Actions and free/open-source tooling without requiring dedicated CI/CD servers such as Jenkins or SonarQube.

---

## Objectives

- Centralize DevSecOps workflows across internal and client repositories.
- Automate security checks throughout the SDLC.
- Run parallel, isolated scanner jobs for faster feedback.
- Aggregate multi-scanner results into executive Excel workbooks and responsive HTML email dashboards.
- Use GitHub Actions and open-source tooling (Gitleaks, Trivy).
- Enforce quality gates preventing insecure code from progressing silently.
- Enable simple onboarding of new repositories.

---

## Core Capabilities

### 1. Parallel Security Scanning
- **Secret Detection (Gitleaks)**: Scans Git history and commits for exposed credentials, API keys, and sensitive tokens.
- **Vulnerability & Misconfiguration Scanning (Trivy)**: Scans filesystems, software dependencies (npm, pip, etc.), and configuration files for known CVEs and security flaws.
- **Concurrent Job Execution**: Scanners run as independent, parallel jobs on GitHub-hosted runners to optimize pipeline duration.

### 2. Unified Reporting & Gating
- **Executive Excel Dashboard**: Generated by [`scripts/generate_security_report.py`](file:///home/snyder/DevOps/Action-Engine/scripts/generate_security_report.py), compiling findings into styled, filterable sheets for executive review and remediation tracking.
- **Quality Gates**: Workflows fail intentionally when active security findings are detected, while still preserving and publishing all reports.

### 3. Automated Email Notifications
- **HTML Dashboard**: Built via reusable workflow [`send-reports.yml`](file:///home/snyder/DevOps/Action-Engine/.github/workflows/send-reports.yml), presenting pipeline status cards, findings summary tables, and scanned package counts directly in email inboxes.
- **Report Attachments**: Automatically attaches the generated Excel workbook and raw JSON scan reports.
